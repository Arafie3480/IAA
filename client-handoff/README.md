## بسته منبع قابل تحویل

در ریشه ریپو `npm.cmd run package:handoff` را اجرا کنید. خروجی ZIP تاریخ‌دار و `MANIFEST.json` در `artifacts/delivery/` ساخته می‌شود. کد، لوگو، کپی صفحات، مقالات، تنظیمات npm و راهنماها داخل آن‌اند؛ فایل‌های محیطی واقعی و رمزها بسته‌بندی نمی‌شوند. هش هر فایل در خود ZIP بررسی می‌شود.

پس از استخراج، در پوشه حاوی `package.json`، فرمان‌های `npm ci` و `npm run build` و سپس `npm start` را اجرا کنید. Node.js و دسترسی شبکه برای نصب وابستگی‌ها و دریافت فونت‌های build لازم است. ZIP قالب قابل نصب وبزی نیست؛ برای پنل، متن و دارایی‌ها از بسته منتقل می‌شوند.

## هنوز از کارفرما

**کار فریلنسر در مؤسسه:** تکمیل صفحات، منو، لوگو، فرم‌ها و بازبینی موبایل در ویرایشگر بومی وبزی؛ اتصال مرورگر فعلاً قطع است.

**از مالک مؤسسه:** تأیید محتوای نهایی و اطلاع‌رسانی فرم‌ها، مجوز انتشار/ارسال آزمایشی و دسترسی DNS؛ لوگو، آدرس گیرنده و دسترسی وبزی قبلاً دریافت شده‌اند.

**فروشگاه لباس:** تکمیل بریف محصولات، هویت، ارسال و پرداخت و دسترسی نصب WordPress / WooCommerce مربوط به همان فروشگاه؛ شروع طبق ترتیب توافق‌شده پس از سایت مؤسسه.
