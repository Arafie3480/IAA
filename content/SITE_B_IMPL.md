## برنامه زمانی فشرده (~۳–۵ روز کاری)

| روز | تمرکز | خروجی قابل‌نمایش |
|-----|--------|-------------------|
| **D0** | قفل محیط (قبل یا صبح D1) | WP/Woo آماده · RTL · permalink |
| **D1** | شِل + اولین محصول | خانه RTL + ≥۱ محصول واقعی خریدپذیر |
| **D2** | کاتالوگ | Import بقیه · صفحه محصول · موبایل |
| **D3** | سبد/تسویه + COD/سندباکس | سفارش تست در ادمین |
| **D4** | حقوقی + handoff (±درگاه اگر آماده) | صفحات تأییدشده + راهنمای مالک |
| **D5** | بافر اختیاری | باگ‌فیکس پذیرش |

### D0 — قفل محیط
1. تأیید: هاست WP جدا یا Webzi WordPress
2. نصب/فعال‌سازی: WooCommerce · فارسی/RTL · permalink پست‌نام
3. Child theme یا کیت Elementor فروشگاهی سبک؛ لوگو از `public/logo-iaa.png`
4. حقایق ثابت شرکت (در فوتر/تماس) از `src/lib/company.ts`: نام فارسی، ثبت ۹۷۷۶، آدرس، ایمیل پشتیبانی اعلام‌شده

### D1 — شِل + محصول اول (ادغام فاز ۱+۲)
- هدر: لوگو · فروشگاه · سبد | فوتر: ارسال/مرجوعی/تماس + لینک اعتماد به Site A
- خانه: ۱ هیرو + «مشاهده محصولات»
- ویژگی‌های سراسری: `سایز` (±`رنگ`)
- **یک محصول واقعی** end-to-end (بدون ردیف ساختگی)
- *موازی:* کارفرما CSV/تصاویر بقیه را می‌فرستد

### D2 — کاتالوگ
- Import از CSV کارفرما؛ بدون ردیف ساختگی
- لیست دسته · صفحه محصول · تست موبایل کاتالوگ

### D3 — سبد/تسویه + COD/سندباکس (ادغام فاز ۳+۴ حداقلی)
- واحد پول IRR · آدرس ایران‌معقول · ایمیل اعلان به مالک
- سفارش تست با COD یا درگاه سندباکس
- نرخ ارسال ساده **فقط اگر** تعرفه از intake آماده باشد؛ وگرنه تعویق پس از MVP

### D4 — حقوقی + handoff (±نیم‌روز مارکتینگ حداقلی)
- صفحات حقوقی تأییدشده · راهنمای ۱صفحه‌ای مالک
- درگاه ایران زنده **فقط اگر** کلید واقعی آماده؛ وگرنه بعد از MVP
- اعتماد/تماس: لینک برند به Site A کافی است (بدون صفحه مارکتینگ سنگین)

### بعد از MVP (تعویق عمدی)
صفحه درباره کامل · کوپن پیشرفته · جدول ارسال پیچیده · درگاه زنده بدون کلید · سئو/کمپین
