# فروشگاه لباس — فقط مسدودکننده‌های بی‌پاسخ

Site A روی staging برای بازبینی آماده است. **اسکلت/برنامه Site B در ریپو شروع شده** (`/site-b` · PLAN · IMPL).  
ساخت WP/Woo زنده و کاتالوگ واقعی **تا این ۵ مورد جواب نیاید جلو نمی‌رود.**  
فرض نکنید: محصول، قیمت، دامنه، درگاه، یا «همان برند IAA» مگر کارفرما بگوید.

---

## پیام کوتاه برای میزکار (کپی)

```
برای شروع فروشگاه لباس بعد از تأیید سایت مؤسسه، لطفاً این موارد را بفرستید:

۱) برند فروشگاه، لوگو/رنگ، و دامنه (جدا یا ساب‌دامین)
۲) دسترسی امن WordPress/WooCommerce (هاست خودتان یا وبزی WP) — رمز را در چت عمومی ننویسید
۳) فایل محصولات اولیه: نام، دسته، SKU، سایز، رنگ، قیمت ریال، موجودی، تصویر
۴) محدوده و هزینه ارسال + سیاست مرجوعی
۵) روش/درگاه پرداخت ایران + ایمیل یا تلفن پشتیبانی سفارش‌ها

با دریافت این‌ها همان هفته اسکلت فروشگاه را می‌چینم.
```

اختیاری بعداً (مسدودکنندهٔ شروع نیست): کوپن‌ها، باشگاه مشتریان، بلاگ فروشگاه، اتصال اینستاگرام.

پیام Site A فعلی فقط تأیید بصری می‌خواهد؛ متن ۵سؤال بالا را **بعد از OK کارفرما** جدا بفرستید. هیچ دادهٔ محصولی invent نمی‌شود.
