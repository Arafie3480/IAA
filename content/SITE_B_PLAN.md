## A. Scope & DoD

### باید تحویل شود (MVP)
| مورد | تعریف Done |
|------|------------|
| خانه فروشگاه | برند، CTA به فروشگاه، لینک اعتماد (ارسال/مرجوعی) |
| کاتالوگ | حداقل ۱ دسته + لیست محصول با تصویر/قیمت IRR |
| صفحه محصول | تنوع سایز (±رنگ) · موجودی · افزودن به سبد |
| سبد + تسویه | مسیر کامل تا ثبت سفارش در حالت آزمایشی |
| حساب کاربری | ثبت‌نام/ورود استاندارد Woo (اگر کارفرما نخواهد، مهمان‌تسویه کافی است) |
| صفحات حقوقی حداقلی | ارسال · مرجوعی · حریم خصوصی — متن تأییدشدهٔ مالک |
| موبایل RTL | خرید از موبایل بدون شکستگی چیدمان |
| راهنمای مالک | افزودن محصول / سفارش / موجودی (۱ صفحه کوتاه) |

### خارج از اسکوپ مگر بریف جدا بگوید
- بازسازی مؤسسه (Site A) یا ادغام Vida↔Woo
- هدلس / Next.js فروشگاه / اپ موبایل
- اختراع کاتالوگ، قیمت، موجودی، درگاه
- مارکت‌پلیس چندفروشنده، باشگاه مشتریان پیچیده، لایو شاپ
- سئوی پیشرفته / کمپین تبلیغات / تولید عکس محصول

### وابستگی‌ها (ترتیب)
1. **پذیرش Site A** توسط کارفرما (staging یا دامنه)
2. پاسخ [`SITE_B_QUESTIONS.md`](./SITE_B_QUESTIONS.md) — بدون این‌ها ساخت شروع نمی‌شود
3. دسترسی امن WordPress/Woo (یا تأیید «وبزی WP» اگر همان هاست الزام است)
4. فایل کاتالوگ + تصاویر مجاز + سیاست ارسال/مرجوعی + روش پرداخت ایران

## B. رویکرد بهینه (کم‌بازنویسی)

### پشته پیشنهادی
| لایه | انتخاب | چرا |
|------|--------|-----|
| CMS/فروشگاه | **WordPress + WooCommerce** روی هاست کارفرما (یا Webzi WP اگر قید قرارداد است) | قرارداد لباس؛ Elementor فقط برای شِل فروشگاه OK |
| تم | Child theme سبک **یا** کیت آماده Elementor/FSE فروشگاهی | بدون تم سنگین سفارشی از صفر |
| هویت | لوگو + رنگ از Site A (`public/logo-iaa.png`)؛ حقایق شرکت از `src/lib/company.ts` | یکپارچگی برند بدون کپی مؤسسه |
| پرداخت/ارسال | پلاگین درگاه ایران + روش ارسال ساده (نرخ ثابت یا جدول) | بدون درگاه ساختگی |
| ممنوع | هدلس سفارشی · ری‌بیلد Vida · دادهٔ محصول جعلی | ریسک و بازکاری بالا |

### فازبندی MVP (ترتیب ارزش)
| فاز | خروجی | موازی‌سازی |
|-----|--------|------------|
| **0 — Intake** | پاسخ بریف + دسترسی WP + فایل کاتالوگ | — (مسدودکننده) |
| **1 — Shell** | نصب Woo · RTL · هدر/فوتر · لوگو · خانه مینیمال | موازی با آماده‌سازی CSV محصولات توسط کارفرما |
| **2 — Catalog** | دسته · ویژگی سایز/رنگ · import محصول · صفحه محصول | بعد از فاز ۱ برای URLها؛ آماده‌سازی داده از قبل |
| **3 — Cart/Checkout** | سبد · تسویه · ایمیل سفارش تست · صفحه تشکر | بعد از ≥۱ محصول واقعی |
| **4 — Commerce polish** | کوپن · هزینه ارسال · درگاه آزمایشی → زنده | موازی با متن حقوقی |
| **5 — Marketing pages** | درباره برند فروشگاه · تماس · اعتماد | بعد از تثبیت شِل؛ اولویت پایین‌تر از خرید |

### جریان‌های کاری موازی vs ترتیبی
| موازی | ترتیبی (باید پشت‌سرهم) |
|-------|-------------------------|
| شِل تم ↔ آماده‌سازی CSV/تصاویر توسط کارفرما | نصب WP/Woo → تنظیم permalink → محصولات |
| متن ارسال/مرجوعی ↔ تنظیم روش ارسال | محصول → سبد → تسویه → درگاه |
| صفحه تماس فروشگاه ↔ تست موبایل کاتالوگ | درگاه آزمایشی → تأیید مالک → درگاه زنده |

### چک‌لیست intake محتوا/داده (کارفرما)
- [ ] نام برند فروشگاه + دامنه (±ساب‌دامین)
- [ ] لوگو SVG/PNG · پالت رنگ (یا «همان IAA»)
- [ ] دسترسی WP ادمین (کانال امن؛ نه چت عمومی)
- [ ] لیست محصول: نام · دسته · SKU · سایز · رنگ · قیمت IRR · موجودی · تصویر
- [ ] محدوده ارسال · تعرفه/زمان · سیاست مرجوعی
- [ ] واحد پول IRR · درگاه/روش پرداخت ایران‌آماده · تماس پشتیبانی
- [ ] صفحات حقوقی: چه متنی تأیید می‌شود / چه کسی می‌نویسد

### عمداً نمی‌سازیم
کپی بازاریابی جعلی · دامنه فرضی · کاتالوگ ساختگی · درگاه بدون حساب واقعی · ادغام با پنل Vida مؤسسه

## C. تایم‌لاین و ریسک (تخمین فریلنسر پس از intake کامل)

| مایل‌استون | برآورد پس از دسترسی+داده | خروجی قابل‌نمایش |
|------------|--------------------------|-------------------|
| M1 Shell | ۱–۲ روز | خانه + فروشگاه خالی RTL |
| M2 Catalog | ۱–۳ روز (وابسته به تعداد SKU) | محصولات قابل‌خرید تستی |
| M3 Checkout | ۱–۲ روز | سفارش تست بدون پرداخت زنده |
| M4 Pay/Ship | ۱–۳ روز | درگاه/ارسال آزمایشی → تأیید |
| M5 Polish + handoff | ۱ روز | صفحات حقوقی + راهنمای مالک |

**جمع واقع‌بینانه MVP:** حدود **۵–۱۰ روز کاری** بعد از intake کامل — نه از روز پرسش.

### ریسک‌ها / مسدودکننده‌ها
| ریسک | اثر | کاهش |
|------|-----|------|
| نبود کاتالوگ/تصویر | توقف فاز ۲ | قالب CSV از روز اول؛ بدون داده ساخت شروع نشود |
| درگاه پرداخت ایران | توقف پرداخت زنده | اول COD/کارت‌به‌کارت یا درگاه آزمایشی؛ زنده بعد از تأیید مالک |
| هاست/نسخه PHP یا محدودیت Webzi WP | تأخیر نصب | تأیید محیط قبل از M1 |
| صفحات حقوقی ناقص | ریسک انتشار | پیش‌نویس کوتاه از مالک؛ بدون تأیید منتشر نشود |
| موجودی/SKU بی‌نظم | باگ تنوع‌ها | یک ویژگی استاندارد سایز قبل از import انبوه |
| انتظار ادغام با Site A Vida | اسکوپ‌خزش | صریح: دو سایت جدا؛ حداکثر لینک متقابل فوتر |
