# ساخت ایمیل سازمانی روی هاست ایران (برای کارفرما)

هدف: آدرسی مثل `join@iaafuture.com` — **جیمیل نیست**؛ روی همان هاستی ساخته می‌شود که دامنه به آن وصل است.

> اگر ساختن سخت بود: فعلاً **همان جیمیل شخصی** برای مقصد فرم‌ها کافی است. فقط آدرس جیمیل را بفرستید (رمز لازم نیست).

---

## کجا ساخته می‌شود؟

| جا | چه موقع |
|----|---------|
| **هاست ایران** (cPanel یا DirectAdmin) | رایج‌ترین راه — دامنه باید روی همان هاست باشد |
| **پنل وبزی** → ایمیل / ایمیل سازمانی | فقط اگر پلن‌تان ایمیل داشته باشد (مثلاً Corporate؛ پلن Team اغلب ندارد) |
| جیمیل / Outlook شخصی | **نمی‌تواند** `join@iaafuture.com` بسازد |

---

## اگر پنل‌تان cPanel است

1. وارد پنل هاست شوید (لینک و رمز از شرکت هاستینگ).
2. دنبال **Email Accounts** یا «حساب‌های ایمیل» بگردید.
3. **Create** / ایجاد حساب.
4. نام کاربری: `join` → دامنه: `iaafuture.com` → رمز قوی → Create.
5. تمام. آدرس می‌شود: `join@iaafuture.com`.

SMTP (اگر از شما خواسته شد، معمولاً از همان صفحه یا Connect Devices):

- Host: اغلب `mail.iaafuture.com`
- Port: `465` (SSL) یا `587` (TLS)
- User = همان آدرس ایمیل · Pass = رمزی که گذاشتید  
  **رمز را در چت عمومی کارلنسر نفرستید.**

---

## اگر پنل‌تان DirectAdmin است

1. **E-mail Accounts** → Create.
2. `join@iaafuture.com` + رمز → Create.
3. مشخصات SMTP را از راهنمای هاست یا همان بخش کپی کنید.

---

## بعد از ساخت چه بفرستید؟

حداقل: فقط آدرس (`join@iaafuture.com` یا جیمیل شخصی).  
برای تست کامل SMTP (اختیاری): host / port / نوع SSL — **رمز جدا و امن.**
